# Utilities
A Utility in PGE3 is a single header file, assistive set of data structures, classes and algorithms intended to simplify common procedures. For example, the Camera2D utility will transform a game world to the screen in various ways, and the QuadTree can partition 2D space for efficient search or rendering.

The core PGE3 doesn't rely upon utilities meaning they are entirely optional, however utilities and extensions may rely upon other utilities.

Documentation for a utility if not obvious, should be included within the utility file itself.
